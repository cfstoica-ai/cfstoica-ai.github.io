signalfeed-backup

signalfeed-backup is a personal backup tool. It is used by one person, the owner of this site, to back up their own server.

Every night it uses restic and rclone to create encrypted backup files in the owner's own Google Drive, and to read and tidy up those same files later.

It asks Google only for the drive.file permission, so it can reach only the files it created itself, never the rest of the Drive. It is not offered to anyone else.
